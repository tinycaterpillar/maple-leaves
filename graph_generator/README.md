# Self-Complementary Graph Candidate Degree Sequence Generator

This program is designed to **enumerate candidate degree sequences** that could correspond to **self-complementary graphs**. It also generates **one** of the possible graphs (note that many graphs can share the same degree sequence) and **checks whether it is self-complementary**.

⚠️ Only **simple graphs** are considered — multiple edges and loops are **not allowed**.

## 🧪 Graph Isomorphism Test Pipeline

This project automatically checks whether each generated graph and its complement are **isomorphic**, based on a given number of vertices `n`.

The pipeline:

1. **User Input** (number of vertices `n`)
2. **Run** `degree_sequences_generator`
3. **Run** `graph_generator`
4. **Run** `complement_graph`
5. **Run** `isomorphic_test.py`

## 🔧 Program: `degree_sequences_generator`

- **Input**  
  An integer `n`, representing the number of vertices.  
  `n` must be of the form **4k** or **4k + 1**.

- **Output**  
  A list of degree sequences that are graphic and satisfy all of the following conditions:

  1. **Graphic Sequence**  
     The sequence satisfies the **Erdős–Gallai theorem**,  
     i.e., it corresponds to some *simple graph*.

  2. **Half Edge Count**  
     The sum of the degrees is  
     \[
     \sum d_i = \binom{n}{2}
     \]  
     meaning the corresponding graph has exactly **half** the number of edges of a complete graph of order `n`.

  3. **Complement Symmetry**  
     The sequence is symmetric with respect to the complement:  
     \[
     d_i + d_{n + 1 - i} = n - 1 \quad \text{for all } i = 1, 2, \dots, n
     \]  
     This ensures that the graph and its complement have the **same degree sequence**,  
     a necessary condition for self-complementarity.


## 🏗️ Program: `graph_generator`

- **Input**  
  A list of degree sequences generated by `degree_sequences_generator`.

- **Output**  
  A text file `graph_{i}.txt` for each valid sequence, representing a **simple graph** that realizes the degree sequence.

- **Details**  
  Each file contains:
  - The number of vertices `n`
  - A list of undirected edges (as `u v` pairs, one per line)
  - The degree sequence on the last line

  This program uses the **Havel–Hakimi algorithm** to greedily construct graphs from given degree sequences, ensuring realizability.

⚠️ Note: There may exist non-isomorphic graphs that share the same degree sequence. The Havel–Hakimi algorithm generates only one such graph for a given sequence.

## 🧪 Program:  `isomorphic_test.py`

- **Input:**  
  Graph files (`graph_*.txt`) and their complements (`complement_*.txt`) from the `data/` directory.

- **Process:**  
  1. Loads adjacency matrices from files.  
  2. Uses `networkx.is_isomorphic()` (VF2 algorithm) to compare each pair.  
  3. Prints whether the graph and its complement are **isomorphic**.

- **Output:**  
  For each degree sequence:
  - ✔ if the graph is isomorphic to its complement (i.e., self-complementary realization)  
  - ✘ if not
